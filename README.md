# UsageBar

UsageBar is a lightweight macOS menu bar application that helps you monitor usage limits across Codex and Claude Code.

The application provides a quick overview of usage directly from the macOS menu bar and supports multiple providers, including Codex, Claude Code, Anthropic API, and custom HTTP endpoints.

## Features

- Monitor Codex usage.
- Estimate Claude Code usage from local logs.
- Display Anthropic API rate-limit information.
- Support custom HTTP usage providers.
- Store credentials securely in the macOS Keychain.
- Receive optional usage notifications.
- Simple and lightweight menu bar interface.

## Installation

1. Download the latest `.dmg` file from the [Releases](../../releases) section.
2. Open the downloaded disk image.
3. Drag `UsageBar.app` to the `Applications` folder.
4. Launch UsageBar from Applications.

## Requirements

- macOS 13 or later.

## Privacy

UsageBar processes usage information locally whenever possible. API credentials are stored in the macOS Keychain, while Claude Code usage is estimated from local session logs.

Review the application configuration before using it with production credentials.
